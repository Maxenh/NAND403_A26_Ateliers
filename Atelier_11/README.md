Utilisation de l'outil de génération de roche:

Lors de l'ouverture de maya à partir de VS Code, sélectionner le nombre de subdivisions avant d'appuyer sur le bouton de création.
La subdivision n'est applicable qu'a chaque génération et est définitive pour cette instance de roche ensuite.

Une fois la roche créer, il est possible d'ajuster les paramètres d'amplitude, de fréquence ainsi que la seed.
lorsque l'apparence de la roche vous suffit, ajuster la subdivision pour la prochaine roche et cliquer sur le bouton de création.
les paramètres seront sauvegardé pour cette roche et la suivante sera créer avec la subdivision voulu.
